# 📊 Business KPI Dashboard – Web Traffic & Weekly Visits Analysis

An interactive **Excel Business KPI Dashboard** designed to analyze website traffic, visitor engagement, conversion performance, bounce rate, traffic sources, campaigns, and page performance.

This project combines **Excel Pivot Tables, Pivot Charts, Slicers, KPI Cards, formulas, and VBA Macros** to create an interactive and automated business reporting solution.

---

## 📌 Project Overview

The **Business KPI Dashboard – Web Traffic & Weekly Visits Analysis** provides a centralized view of important website performance metrics and helps businesses monitor traffic, user engagement, conversion performance, and marketing effectiveness.

The dashboard allows users to analyze:

* Website Visits
* Traffic Sources
* User Types
* Page Views
* Bounce Rate
* Session Duration
* Pages per Visit
* Conversion Rate
* Campaign Performance
* Page Performance
* Traffic Channel Performance

## 📊 KPI Summary

| KPI                        | Description                                                |
| -------------------------- | ---------------------------------------------------------- |
| **Total Visits**           | Total number of website visits                             |
| **Avg. Session Duration**  | Average time users spend during a session                  |
| **Pages per Visit**        | Average number of pages viewed per visit                   |
| **Bounce Rate %**          | Percentage of visitors leaving without further interaction |
| **Page Views**             | Total number of pages viewed                               |
| **Goal Conversion Rate %** | Percentage of visits resulting in a goal conversion        |
